# 📚 Poetry Author Prediction using Machine Learning

This project is based on *Natural Language Processing (NLP)* and *Machine Learning, where the system predicts the **author of a poem* based on the input text.

---

## 🚀 Project Overview

The main objective of this project is to analyze poetry text and identify its author using different machine learning models.  

User can enter any line of poetry, and the system will predict the most likely author.

---

## 🧠 Models Used

The following machine learning models are used and compared:

- Logistic Regression  
- Naive Bayes  
- Support Vector Machine (SVM)  
- K-Nearest Neighbors (KNN)  
- Decision Tree  
- Random Forest  

---

## ⚙️ Features

- Text preprocessing (cleaning, tokenization)
- Label encoding of authors
- Model training and evaluation
- Comparison of multiple ML models
- GUI for user interaction
- Real-time author prediction
